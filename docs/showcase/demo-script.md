# 5 分钟演示脚本（Demo Script）

面向：演示/评审/录屏。全程约 5 分钟，13 步。每步含"操作 → 话术 → 预期画面"。
前置：干净环境（建议先删除 `%APPDATA%\DeepSeekBalanceWidget\` 还原首次运行状态）；屏幕右下角任务栏可见。

> 截图对照：[README 截图区](../../README.md#截图) 与 `assets/`。演示过程不涉及真实 API Key（第 9 步用占位符 Key 演示保存动作即可，或跳过）。

## 第 1 步（0:00–0:30）启动：托盘状态灯亮起

- **操作**：双击 `DeepSeekBalanceWidget.exe`（单文件，无需安装）。
- **话术**："一个 63 MiB 的单文件，双击就跑，不需要装 .NET。"
- **预期画面**：约 1 秒内任务栏通知区出现一枚**圆形状态点**（新装通常在溢出弹层"^"内，点开展示）；悬停 tooltip："DeepSeek 余额小组件 · 高峰/空闲时段"。圆点颜色与当前时段一致（工作日高峰=橙，空闲/周末/节假日=绿）。

## 第 2 步（0:30–1:00）左键弹出面板

- **操作**：左键单击托盘圆点。
- **话术**："左键弹出信息面板——余额、峰谷倒计时、时段进度一目了然。"
- **预期画面**：光标附近弹出 320×230 圆角面板：状态胶囊（高峰/空闲）、余额区、倒计时（HH:mm:ss 逐秒跳动）、4px 进度条、底部"上次刷新"。未配置 Key 时余额区显示"请先在设置中配置 API Key"（这本身是正确状态）。

## 第 3 步（1:00–1:30）四态主题

- **操作**：右键托盘圆点 → 设置 → 主题切"浅色"→ 切回"深色"→ 关闭设置窗口。
- **话术**："浅色/深色/跟随系统三模式，切换即时生效。"
- **预期画面**：设置窗口、面板、托盘图标三处同步换色；重新打开面板可见另一主题的面板。

## 第 4 步（1:30–2:00）倒计时与峰谷判定（离线）

- **操作**：指着面板倒计时与进度条讲解（可等待数秒观察逐秒递减）。
- **话术**："峰谷判定完全离线：工作日 9–12、14–18 高峰；周末一律空闲；法定节假日按'本地星期优先'规则——调休补班的周末不会被 API 误判成工作日。跨长假倒计时直接显示总小时数，比如 95:00:00。"
- **预期画面**：倒计时数字等宽逐秒递减；绿条按「剩余 ÷ 总长」等比例收缩（与倒计时同源同值，数字归零瞬间绿条恰好归零、翻入新时段立即回满），条上有淡白流光自左向右匀速扫过。

## 第 5 步（2:00–2:40）v1.1 右缘停靠 + 拖动吸附

- **操作**：① 若有位置记忆先删除 `%APPDATA%\DeepSeekBalanceWidget\settings.json` 并重启（演示默认停靠）；② 左键托盘弹出面板；③ 按住面板空白处拖到屏幕中部松手；④ 再拖回右缘附近（可见卡片右缘距屏幕右缘 <28px）松手。
- **话术**："无位置记忆时面板默认停靠屏幕右缘、任务栏上方；按住空白处可以拖动，靠近右缘自动吸附贴边。"
- **预期画面**：面板默认出现在右缘（卡片贴边）；拖动全程贴合光标；释放后水平吸附贴右缘、垂直位置保持。

## 第 6 步（2:40–3:10）钉住面板

- **操作**：点击面板顶行**图钉钮**；然后点击桌面（让面板失焦）。
- **话术**："图钉一按，面板失焦不再隐藏——常驻显示。托盘菜单里也有'钉住面板'勾选项，两处状态实时同步。"
- **预期画面**：图钉变强调色填充；点击桌面后面板**保持显示**（未钉时同类操作面板会隐藏）；右键托盘可见"钉住面板"已勾选。

## 第 7 步（3:10–3:30）钉住时置顶开关

- **操作**：右键托盘 → 设置 → 切换"钉住时置顶"开关 → 关闭设置窗口。
- **话术**："钉住时是否置顶可配置，默认开。"
- **预期画面**：开关切换后面板层级即时变化（关 = 可被其他窗口遮挡；开 = 始终置顶）。

## 第 8 步（3:30–4:00）取消钉住 + 失焦隐藏 + 位置记忆

- **操作**：再点图钉取消钉住 → 点击桌面（面板隐藏）→ 左键托盘重现面板。
- **话术**："未钉住时失焦自动隐藏；拖动后的位置跨启动记忆——重启应用后面板还在这个位置（但不会自动弹出，保持安静常驻）。"
- **预期画面**：失焦后面板消失；托盘左键在**记忆位置**重现。

## 第 9 步（4:00–4:30）配置 API Key（可选演示）

- **操作**：右键托盘 → 设置 → 粘贴 Key（演示可用占位符 `sk-xxxx`，或跳过本步）→ "保存 Key" → 手动点面板刷新按钮。
- **话术**："Key 只存 Windows 凭据管理器，不落文件、不进日志——日志里有专门一层'出现即打码'。"
- **预期画面**：真实 Key 时余额区显示 `¥ 数字`；无效 Key 时显示"API Key 无效，请检查设置"（真实 401，1/5/15 分钟退避后自动重试）；未配置/清除后回到提示态。

## 第 10 步（4:30–5:00）退出与清理

- **操作**：右键托盘 → 退出。
- **话术**："退出链完整：托盘图标移除、临时图标目录清理、单实例 Mutex 释放。数据都在用户目录，完全卸载 = 退出 + 删目录 + 删凭据，三条命令。"
- **预期画面**：托盘圆点消失；任务管理器无 `DeepSeekBalanceWidget.exe` 进程。

## 录屏/拍摄注意

1. 面板是 Topmost 分层窗口，录屏请用窗口级捕获或 PrintWindow 类工具（全屏 GDI 抓帧可能丢失面板）。
2. 高峰/空闲两态的自然切换点为工作日 09:00/12:00/14:00/18:00（北京时间）；节假日全天空闲，如需两态对比可口头说明或引用 README 截图。
3. 若图标在溢出弹层内，"左键切换"表现为"总是显示、失焦隐藏"（Shell 焦点语义）——演示前建议把图标固定到任务栏可见区。
