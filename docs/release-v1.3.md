# Release v1.3 — 启动初始化定位

DeepSeek 余额峰谷监控小组件 v1.3。

## 下载

- **DeepSeekBalanceWidget.exe**（见下方 Assets）：Windows x64 自包含单文件，免安装、免 .NET 环境。同目录需保留 5 个 WPF 原生依赖 DLL（已一并提供）。

## 本版新功能（需求变更 2026-10-15）

**启动初始化定位——每次启动强制停靠主屏右下角**

- 每次启动（开机/进程首次显示）时自动读取屏幕工作区信息，强制把面板停靠在**主显示器右下角**（可见卡片贴右缘、任务栏上方 12px），忽略 settings.json 中的旧记忆位；
- 彻底避免钉住状态下切换/断开显示器后，旧记忆位落在屏幕外导致面板不可见的问题；
- 停靠后立即将该位置落盘为新记忆位（覆盖原配置）；
- 运行期间保留拖动记忆：之后移动到哪里记到哪里；
- 记忆位不可达（如运行中拔掉副屏导致出屏）时自动回退主屏右下角停靠，且修正后落盘。

## 安装与运行

1. 下载 Release 压缩包或 Assets 中的文件到同一文件夹；
2. 若 SmartScreen 拦截："更多信息" → "仍要运行"；
3. 双击运行：任务栏通知区出现状态圆点图标，面板停靠在主屏右下角；
4. 右键图标 → "设置" → 粘贴 DeepSeek API Key（sk- 开头）→ "保存 Key"。不配置也可用：峰谷/倒计时/进度/主题全部离线可用，仅余额区提示。
