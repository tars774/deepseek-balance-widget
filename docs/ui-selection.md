## 1. 布局规范（320 × 230，单列自上而下）

面板：宽 **320px**、高 **230px**，无边框，圆角 **14px**，阴影 `0 10px 26px rgba(15,23,42,.16)`，内边距 `14px 16px`，纵向单列布局，各区间距如下：

```
┌────────────────────────────────────────┐
│ [状态胶囊]              (⚙)(⟳)  ← 顶行 │  顶行两端对齐
│                                        │
│ ¥ 110.00                       ← 余额区│  顶行下 18px
│ 总  余  额                              │
│                                        │
│ 距空闲时段还有 01:23:45         ← 倒计时│  余额区下 16px
│ ▓▓▓▓▓▓▓▓░░░░░░░░░░░                    │  文字下 8px
│                                        │
│ 上次刷新 今天 14:32            ← 底部行│  margin-top:auto 吸底
└────────────────────────────────────────┘
```

## 4. 字体与数字

- 系统字体栈（实现采用 Segoe UI 优先，回退微软雅黑）；数字使用等宽数字变体（tabular-nums），保证倒计时每秒跳动不抖动。
- 倒计时格式固定 `HH:mm:ss`。

## 5. 预览未覆盖、由需求推导的实现性补充约定

以下状态在预览页中未单独渲染，实现时沿用 A1 的色阶与布局语言，作为本规范的一部分：

1. **未配置 / API Key 无效**：余额区显示"请先在设置中配置 API Key"（`--sub` 色，12–13px），整块可点击打开设置窗口；余额数字位置不显示缓存值。
2. **网络失败**：余额区显示简短错误提示（如"余额获取失败"，`--sub` 色）；**不显示过期缓存余额**；倒计时/进度条/状态标签照常显示（离线可用）。
3. **节假日数据降级提示**：双节假日 API 均失败时，在底部刷新时间行右侧显示一枚 10–12px 的小提示图标（`--muted` 色），悬停提示"节假日数据不可用，已按周一至周五判断"。
4. **刷新中状态**：刷新按钮悬停态即点击反馈；刷新进行中可短暂变为 `--acc-deep` 色（可选，不强制动画）。
5. 设置齿轮、刷新按钮的图标沿用预览页 inline SVG 造型（线性、2px 描边、圆头）。

## 7. v1.1 行为增补（2026-09-30，用户需求变更）

用户于 2026-09-30 确认的行为变更，作为 A1 规范的增补生效。**既有视觉规格全部不变**（面板 320×230 / 圆角 14 / 色板两套 / 字号 / 26×26 圆钮 / 14px 阴影余量视口 348×258 均维持 §1–§6 数值）；本节只新增行为与一个新按钮。

### 7.1 顶行 2 钮 → 3 钮（新增图钉钮）

- 顶行右侧新增**图钉圆钮**：与设置/刷新同款 26×26 圆钮（底色 `--card`、图标 14×14 inline SVG 图钉、线性 2px 描边圆头）。
- **放置顺序 = 图钉居左**：钉住是"模式开关"，设置/刷新是"动作按钮"，分区摆放；既有设置/刷新两钮的相对位置与规格不变。
- 状态视觉：**未钉 = 描边常态色**（图标描边 `--sub`）；**已钉 = 填充强调色**（图标整体填充 + 前景 `--acc`）；悬停变 `--acc` 与既有按钮一致。tooltip 随状态切换（"钉住面板" / "取消钉住"）。
- 托盘右键菜单新增"**钉住面板**"**勾选项**（IsCheckable），与面板图钉钮两处任一操作另一处**立即同步**。

### 7.2 右缘停靠默认位（无位置记忆时）

- 无位置记忆（首次启动 / 旧版配置文件）时，面板弹出位 = **主显示器工作区右缘停靠**：可见卡片右缘贴工作区右缘，窗口底边距工作区底 **12px**（任务栏上方）。
- gutter 换算：窗口含 14px 阴影透明边距，"贴右缘"指可见卡片贴边 → **窗口右缘超出屏幕右缘 14px**（窗口 X = 工作区右缘 + 14 − 348）。
- 多显示器以主屏为准（实现假设，代码注明）。

### 7.3 拖动与右缘吸附

- **拖动**：按住面板任意空白处可拖动；齿轮/刷新/图钉按钮与"未配置 API Key"提示等可交互元素不触发拖动（点击照常）。采用**按下后位移 >4px 才进入拖动**的阈值（防误触设计，常量 `DragThresholdPx=4`）。
- **吸附**：拖动释放后，若可见卡片右缘距工作区右缘 **≤28px**（常量 `SnapThresholdPx=28`）→ 水平自动吸附为贴右缘，垂直位置保持。

### 7.4 位置与钉住状态记忆

- 拖动/吸附结束与钉住切换时，把窗口位置（窗口坐标，含阴影边距）与钉住状态持久化到 `settings.json` 新增字段 `PanelX` / `PanelY` / `Pinned` / `PinTopmost`。
- 重启后面板**不自动弹出**（既有行为不变）；点托盘显示在记忆位置；无记忆字段时走 §7.2 默认停靠。

### 7.5 钉住行为与置顶配置

- **钉住**时面板失焦（Deactivated）**不隐藏**；未钉住的失焦自动隐藏与显示侧 300ms / 隐藏侧 250ms 防抖逻辑不变。
- 托盘左键切换语义不变：钉住但被左键收起后，再点托盘重现于记忆位置。
- 设置窗口新增"**钉住时置顶**"开关（默认**开**）：开 = 钉住时面板 Topmost；关 = 钉住时普通层级（可被遮挡）；**未钉住弹出时始终 Topmost**（现状）。切换开关 / 钉住状态时 Topmost 即时正确切换；钉住且非置顶时托盘左键重现面板仍能带到前台。
