## 1. 功能清单

- **托盘常驻 + 峰谷状态灯**：橙色 = 高峰时段、绿色 = 空闲时段（深浅主题各两枚变体图标，A1 语义色精确值）；tooltip 实时"DeepSeek 余额小组件 · 高峰/空闲时段"。
- **A1 弹出面板（320×230）**：状态胶囊、总余额区、倒计时（HH:mm:ss，tabular-nums 防抖动）、4px 进度条（当前时段已过比例）、上次刷新时间行；左键托盘图标弹出/隐藏，失焦自动隐藏。
- **峰谷判定（北京时间）**：工作日 09:00–12:00、14:00–18:00 高峰，其余空闲；周六/周日一律全天空闲；法定节假日按"本地星期优先"规则（API 报节假日且为周一至五才生效，调休补班日不误判）。
- **节假日数据双源拉取**：主源（xiaoai）+ 备源（dreace）自动切换，按北京日期缓存、跨天重拉、前瞻 400 天；双源失败进入 1/5/15 分钟退避，恢复后立即刷新快照并在底行显示"节假日数据不可用，已按周一至五判断"小提示。
- **余额查询**：DeepSeek 官方 `/user/balance` 接口；API Key 仅存 Windows 凭据管理器（本机）；30 分钟后台巡查 + 打开面板即刷（30s 去抖）+ 手动刷新按钮三触发源；失败精确分类（401/DNS/超时/畸形 JSON）并按 1/5/15 分钟退避。
- **定时巡查引擎**：1 秒心跳（伺服式绝对对齐，实测 mean 1000.0ms、漂移 ±15ms 量级），倒计时/进度每秒直刷，状态翻转沿同步托盘/胶囊。
- **设置窗口**：API Key 保存/清除、后台刷新间隔（5–1440 分钟，即时生效）、开机自启（HKCU Run，默认关）、主题三模式（跟随系统/浅色/深色，即时生效并持久化）、可选手动余额模式（无 Key 时本地展示）。
- **主题**：完整 A1 浅/深两套色板，跟随系统变化实时切换。
- **健壮性**：单实例 Mutex；全局异常兜底；日志按日滚动、全量脱敏（0 Key / 0 Authorization）；退出全清理（托盘/图标文件/Mutex）。
- **v1.1 增补（2026-09-30）：面板右缘停靠 + 拖动吸附**——无位置记忆时面板默认停靠主屏工作区右缘（可见卡片贴右缘、任务栏上方 12px，含 14px 阴影边距换算）；按住空白处可拖动（>4px 阈值防误触，按钮/提示等可交互元素不触发），释放后距右缘 ≤28px 自动吸附贴边。
- **v1.1 增补（2026-09-30）：钉住面板**——面板顶行新增图钉圆钮（未钉=描边常态色、已钉=填充强调色）+ 托盘菜单"钉住面板"勾选项，两处状态实时同步；钉住时失焦不隐藏，钉住时置顶可配置（设置窗口"钉住时置顶"开关，默认开）。
- **v1.1 修复（2026-10-01，FB-1）**：法定节假日的工作日启动时，托盘图标与胶囊强调色曾停留在"高峰橙"（启动首帧快照早于节假日数据到达，恢复重算的翻转沿被初始化语义吸收）——现已根治：启动首帧已发布状态作为翻转沿基准，数据到达后补发恰一次状态变更，托盘/胶囊立即纠正为空闲绿；新增 2 个回归用例（延迟节假日源时序 + 工作日不误翻对照），集成测试 41→43 用例（详见 [test-report.md §7](test-report.md)、[probe-results.md](probe-results.md)）。
- **v1.1 增补（2026-09-30）：位置记忆与置顶配置**——拖动/吸附与钉住状态持久化到 settings.json（PanelX/PanelY/Pinned/PinTopmost），重启后点托盘显示在记忆位置（仍不自动弹出）；未钉住弹出始终置顶（现状不变）。
- **v1.2 增补（2026-10-02）：进度条「剩余口径」**——4px 进度条由旧「当前时段已过比例」改为**剩余÷总长**口径（与倒计时同源计算，旧口径已废弃删除）：倒计时每减 1 秒进度条同步缩短，条长与 HH:mm:ss 严格逐秒同步，语义为"本时段还剩多少"。
- **v1.2 增补（2026-10-02）：绿条流光扫过动画**——淡白高光带沿进度条自左向右周期扫过（关闭时绿条纯色静止）；设置窗口新增「流光效果」节（开关 + 节奏「克制/明显」× 强度「极淡/可见」四档），即时生效并持久化，默认开（克制 × 极淡）。
- **v1.2 增补（2026-10-02）：面板显示期余额 5s 快轮询**——面板显示期间余额刷新固定提速为每 5 秒（固定策略，不设设置项）；面板隐藏即回到后台设定周期，重显先立即刷一次再进入快轮询节奏；快轮询失败按 5→10→20→40→60s 指数退避（60s 封顶），成功即恢复 5s。集成测试 43→56 用例。

## 2. 已知限制（发布前必读）

1. **未签名**：exe 无代码签名（NotSigned）。经浏览器/聊天工具下载后首次运行会触发 SmartScreen"Windows 已保护你的电脑"，需点"更多信息 → 仍要运行"（见部署文档 §4）。对外分发前建议签名。
2. **Win10 未实测**：Win11 全量实测通过；Win10 因无真机未测。技术兼容性依据充分（零 Win11-only API、自包含运行时），请按部署文档 §6 的 **Win10 人工验证清单（约 5 分钟）** 在真机确认后再大规模分发。
3. **托盘图标在溢出折叠区时左键行为（A-5）**：图标位于任务栏溢出弹层内时，左键单击表现为"总是显示面板、隐藏交给失焦"（弹层展开动作本身使面板失焦）；完整切换体验请右键任务栏 → 将"DeepSeek 余额小组件"固定到任务栏可见区。
4. **余额 0.00 显示**：0 余额账号查询为普通成功，面板显示 `¥ 0.00` 并附"余额不可调用"提示（is_available=false 仅展示态，非错误）。若未配置 Key，余额区显示"请先在设置中配置 API Key"。
5. **无自动化测试全覆盖**：`tests/` 集成测试工程（56 用例；v1.1 增补面板定位/钉住/持久化测试；FB-1 回归 2 例；v1.2 增补流光动画与显示期快轮询用例）覆盖核心联动管线；UI 交互、多显示器/DPI、系统睡眠唤醒、8 小时级长跑等未纳入自动测试（部分为阶段 4/5 人工实测项）。
6. **节假日 API 依赖第三方公共接口**：双源均不可用时按周一至周五判断并在 UI 标注（降级保留，不阻塞其他功能）。
7. **余额接口不消耗 token 为低风险既定假设**（官方定位账户查询接口）；默认 30 分钟轮询保守。

## 3. 安装与运行

1. 从发布物获取 `DeepSeekBalanceWidget.exe`（单文件，无需安装）。
2. **（下载场景）** 若 SmartScreen 拦截："更多信息" → "仍要运行"。
3. 双击运行：任务栏通知区出现状态圆点图标（新装通常在溢出弹层"^"内）。
4. 右键图标 → "设置" → 粘贴 DeepSeek API Key（sk- 开头）→ "保存 Key"。不配置也可用：峰谷/倒计时/进度/主题全部离线可用，仅余额区提示。
5. （可选）将图标固定到任务栏可见区以获得完整左键切换体验。

## 5. 数据位置与升级

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 应用日志 | `%APPDATA%\DeepSeekBalanceWidget\logs\app-YYYYMMDD.log` | UTF-8，按日滚动，全量脱敏 |
| 设置文件 | `%APPDATA%\DeepSeekBalanceWidget\settings.json` | 主题/刷新间隔/手动余额；v1.1 新增面板位置与钉住记忆（PanelX/PanelY/Pinned/PinTopmost）；v1.2 新增流光效果（FlowEnabled/FlowSpeed/FlowIntensity）；API Key 绝不在此文件 |
| 图标临时目录 | `%APPDATA%\DeepSeekBalanceWidget\icons\` | 运行时生成，退出自动删除 |
| API Key | Windows 凭据管理器 `DeepSeekBalanceWidget_ApiKey`（Generic，本机） | 控制面板 → 凭据管理器 → Windows 凭据 可见 |
| 单文件解压缓存 | `%TEMP%\.net\DeepSeekBalanceWidget\` | .NET 标准机制（~7.8MB 原生库），删除无副作用（下次首启重建） |
| 开机自启 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（仅勾选自启后写入） | 默认不写 |

**升级**：退出运行中实例（托盘右键 → 退出）→ 用新版 exe 替换旧文件即可。全部数据在上述用户目录，版本间兼容；如需彻底重置，删除 `%APPDATA%\DeepSeekBalanceWidget\` 并清除凭据（见 §6）。

## 6. 卸载（完全卸载 = 3 个必做步骤 + 2 个条件步骤）

1. 退出应用：托盘右键 → 退出（确认任务管理器无 `DeepSeekBalanceWidget.exe` 进程）。
2. 删除数据目录：`%APPDATA%\DeepSeekBalanceWidget\`（含日志与设置；icons 已随退出自动清除）。
3. 删除凭据（若配置过 Key）：

```powershell
cmdkey /delete:DeepSeekBalanceWidget_ApiKey
```

4. （若曾开启自启）移除 Run 键：设置窗口关闭自启开关即可，或

```powershell
Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'DeepSeekBalanceWidget'
```

5. 删除 exe 本体。注册表无其他写入、无服务、无驱动——以上即完全卸载。
