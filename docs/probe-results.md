# 探针结果汇总（Probe Results）

项目采用"探针先行"流程：正式实现前，用一次性最小验证工程对每个风险点做真实环境实测（探针 A–E），全部通过后才按实测结论实现。本文汇总五探针结论、关键实测数字、降级判定（P1–P4），以及从探针与验收环节**挽回的真实 bug**——这是本项目最有展示价值的部分之一。

- 探针 A：`probes/probe-a-tray-panel/`（托盘 + 弹出面板骨架）
- 探针 B：`probes/probe-b-balance-cred/`（余额接口 + Credential Manager）
- 探针 C：`probes/probe-c-peak-holiday/`（峰谷判断 + 节假日 API）
- 探针 D：`probes/probe-d-publish/`（单文件发布 + Win10/11 兼容）
- 探针 E：`probes/probe-e-scheduler/`（定时巡查机制）

> 探针工程归档在项目过程档案中，不进入公开仓库；本文保留全部结论与数字。

| 探针 | 验收结果 | 降级判定 | 一句话结论 |

## 探针 A — 托盘 + 弹出面板（8/8）

关键实测：

- 真实鼠标点击托盘图标：面板显示 **10/10**；双向防抖（显示侧 300ms / 隐藏侧 250ms）18 次失焦事件 **0 次误杀**。
- A1 面板四态色板逐像素命中；`WS_EX_TOOLWINDOW`（exStyle=0x80088）、`ShowActivated=false`、Topmost、单实例 Mutex 全部实证。
- **Topmost 面板会吞掉覆盖区内托盘图标的点击**——第一版覆盖式定位下第 2~10 次点击全部落在面板自身；修复为"光标左侧水平避让 20px + 垂直上方 24px"。
- 溢出区行为边界：图标在任务栏溢出弹层内时"左键≈总是显示、失焦隐藏"（弹层焦点语义）；完整切换需固定到可见区——写入用户文档（A-5）。

## 探针 B — 余额接口 + Credential Manager（7/7）

关键实测（真实 Key，账号余额 0）：

- HTTP 200（170/410ms）；响应顶层仅 `is_available`，余额全部嵌套在 `balance_infos[]` 元素内且为**字符串**（`"0.00"`），另有 `granted_balance` / `topped_up_balance` 字段。
- **0 余额账号照常查询成功**——接口行为与余额数额无关；`is_available=false` 仅表示"余额不可调用模型"，非查询错误。
- 四类异常均可精确分类：无效 Key=401（服务端自动把 Key 打码为 `****xxxx` 回显）；DNS 失败=`HttpRequestException←SocketException(HostNotFound)`；超时=`TaskCanceledException←TimeoutException`（约超时点 +23ms）；畸形 JSON=`JsonReaderException`/`JsonException` 两条路径均给出明确错误。
- Credential Manager：CredWriteW→读回→覆盖→删除→`ERROR_NOT_FOUND(1168)` 全链通过、无残留。
- 安全：真实 Key 仅经环境变量注入，UTF-8+UTF-16 双编码字节级扫描全树 **0 泄漏**。

## 探针 C — 峰谷 + 节假日 API（94/94）

关键实测：

- 真实 API 五日期 × 主/备源对拍**全部一致**；两个补班周末（2025-10-11、2025-09-28）**两源字面都报"工作日"**——唯有"本地 `DayOfWeek` 优先"规则能保证补班周末全天空闲（业务正确性基石）。
- 主源成功判定实测为业务层 `code:0` 而非 HTTP 200（任务书"非 200 判失败"口径有误，已按实测修正为 `code∈{0,200}` + 日期回显校验）。
- 倒计时精确差值、**HH 允许 >24**（45:00:00 / 62:00:00 / 95:00:00 实测）；全天空闲日进度 = 当天已过比例。〔进度条口径已于 2026-10-02 改为「剩余 ÷ 总长」，见 [ui-selection.md §8](ui-selection.md)〕
- 缓存按北京日期、每日期恰拉一次、跨天零重复（计数器证明）；退避 1/5/15 分钟封顶循环、成功清零、全局门；前瞻拉取上限 400 天、本地周末短路。
- 主源存在首请求冷启动 8s 超时风险（run 1 真实触发一次，主→备 failover 正确兜底）。
- **P3 判定：降级必须保留**——双源离线时法定节假日无法识别，会把全天空闲日误判为工作日高峰；Degraded 时 UI 必须标注"数据离线"。

## 探针 D — 单文件发布 + Win10/11（通过）

| 形态 | 体积（探针 A 工程） | 说明 |
| --- | --- | --- |
| FDD 单文件 | 2,211,908 B（2.11 MiB） | 需目标机装有 .NET 8 Desktop Runtime |
| **SCD 自包含·压缩（推荐）** | **71,910,187 B（68.58 MiB）** | 免安装、含运行时；正式版同参数实测 66,202,308 B（63.13 MiB，代码负载不同）——v1.2 起正式版为 66,206,404 B / 63.14 MiB，见 [deployment.md §2](deployment.md) |
| SCD 自包含·不压缩 | 162,056,901 B（154.55 MiB） | 无启动收益，不分发 |

- 三形态均"严格单文件"（1 个 exe、0 伴随文件，wpfgfx/PresentationNative/D3DCompiler/vcruntime/PenImc 全部内嵌）。
- 干净目录 + 最小 PATH 自包含运行成功；首启解压 5 个原生库 ~7.8MiB 到 `%TEMP%\.net` 仅 **+36ms**；托盘就绪 0.9–1.3s。
- 验收方独立重发布产物与执行者产物 **SHA-256 逐字节一致**。
- Win11（build 26200）实测通过；Win10 未实测、未假装——源码核查零 Win11-only API（圆角为纯 WPF 路线），.NET 8 官方矩阵 Win10 仅 LTSC/Enterprise 口径，附 7 步人工验证清单。

## 降级判定（P1–P4）

| 路径 | 判定 | 落地形态 |
| --- | --- | --- |
| P1 托盘 + 弹出面板 | 不需要降级 | 直接采用；仅沉淀"溢出区左键行为"用户说明（A-5） |
| P2 余额接口 + 凭据 | 技术上不需要 | 保留**产品级可选降级**：用户不提供 Key 时可在设置中手动输入余额（仅本地展示，峰谷功能不受影响） |
| P3 峰谷 + 节假日 | **降级必须保留（常驻容错）** | 双源失败/退避窗口 → 仅周一至五本地逻辑照常 + UI"数据离线"标注 |

## 从探针 / 验收中挽回的 bug（展示素材）

正式实现前后的验证环节共拦截/修复了以下真实缺陷——每一项都有失败实录与修复后回归证据：

| # | 缺陷 | 发现环节 | 后果（若未拦截） | 修复 |
| --- | --- | --- | --- | --- |
| 1 | **ICO 通道反色**：手写 ICO 的 DIB 写入 R/B 通道写反（`#E4720B` 橙 → `#0B72E4` 蓝） | 探针 A | 托盘图标颜色错误 | 修正 BGRA 通道顺序；集成测试对 4 枚变体逐像素断言 A1 色值 |
| 2 | **心跳重排语义**：WPF 在 Tick 处理器内修改 `Interval` 时按**旧到期点**重排（与直觉相反），原对齐公式把量化迟到做二次补偿——每 3–8 tick 成对多打 1 拍、每对吞掉 ~1s（三模式对照：朴素/原公式/伺服 = +4.9 / **−2978.6** / +3.4ms） | 探针 E 首轮 real 全 FAIL | 心跳系统性漂移、倒计时跳秒 | 伺服式重排 `Interval = clamp(Heartbeat − e, 250, 2000)` + 跳槽位追赶；设计文档按实测修订 |
